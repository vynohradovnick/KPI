# StageCue

Підказки для оператора демонстраційного стенда. Команда: Виноградов
Ніколай Денисович і Кузьменко Юлія Сергіївна, ІО-з31.

Плата Nucleo-C031C6. Середовище: Ubuntu 24.04, Docker, STM32 HAL, Wokwi.

```sh
make build
```

У VS Code відкрийте корінь проєкту та запустіть **Wokwi: Start Simulator**.
Гілка `lab1` містить перевірку UART/LED. Гілка `lab2` опитує
PIR, LDR і MPU-6050 та видає телеметрію через USART2, 115200 8N1.

- [Дослідження компонентів](docs/hardware-components.md)
